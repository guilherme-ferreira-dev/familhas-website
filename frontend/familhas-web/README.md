# familhas-web

Loja da Familhas (Angular 22, standalone, zoneless). Busca, detalhe de pacote, cotação, checkout e acesso ao WhatsApp.

## Pré-requisitos

- Node 24 LTS (`.nvmrc`)

## Comandos

```bash
npm ci
npm start            # http://localhost:4200
npm run lint
npm run test:ci
npm run build
```
